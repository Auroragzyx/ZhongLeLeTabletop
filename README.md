# 众乐乐桌游 (PARTY TABLETOP • 多元桌游工坊)

面向 PC / Steam 平台规划的多人合集桌游客户端原型，采用零外部网络依赖的离线单页引擎与 Three.js WebGL 3D 桌面渲染。

## 已实现内容

- **大厅与开房系统**：暖阳黄白 / 夜间深空双主题、圆角 / 方正 UI 形态切换、画面亮度滑动条、主音量控制，以及单人人机 / 局域网 / 多人联机建房 3 步配置向导。
- **模式一：《日夜飞行棋》3D（实机可玩）**：
  - 4 套基于 3D 几何建模的手办级灵禽棋子（1P 蓝羽夜鸮、2P 晨曦灵雀、3P 冥夜紫鸦、4P 霞光粉鹦），实时离屏渲染 HUD 头像；
  - 17×17 经典对称十字飞行棋盘，底层搭载 **动态星空底板**（星云、闪烁星辰与流星）+ **星月湖畔实景舞台**；
  - 开局摇骰定先后顺序（点数越大越先、同点自动加赛、结果停留 8 秒）、完整飞行棋规则（自定义起飞点数、外圈同色 +4 顺风连跳、跨盘虚线快捷飞跃、踩子压扁+两波 3D 爆炸烟花返巢、6 步冲刺折返、投 6 连掷奖励、昼夜 8%/2% 奖惩机制）与启发式智能 AI；
  - **观众席、全员投票与 AI 接管底座**：首位胜者完赛触发 15 秒全员结束投票（满 3 票提前按进度结算），否则进入 `1x / 4x` 观众席继续观战直至 4 位全部完赛生成 1~4 名领奖台总榜，并内置 `seatControllers` 通用席位 AI 接管状态机。
- **模式二：《星轨五子棋》3D（实机可玩）**：
  - 宇宙行星星云全景舞台、`2048×2048` 深空占星盘、顺时针黄圈太阳与逆时针紫圈月亮双串环、180 颗浮动星尘，`虚空黑子` / `耀斑恒星` 3D 能量环棋子与 5 连星空烟花；
  - 支持 `星轨共鸣`（3+/4+ 连子点亮紫金连接光束）与经典双模式、左键旋转 / 正交俯视视角切换、开房自定义悔棋次数（关闭或 1~3 次）、落子 6 秒悔棋等待窗、人机 AI 回应与联机 10 秒对手同意弹窗底座、步数显示、`星象推演` 提示、换先及 3 档难度 AI（含 2-ply 前瞻）。
- **规划模式（后续研发）**：《机械大亨 (Gear Tycoon)》、局域网 / 多人联机同步通信与 DLC 扩展模块。

## 本地启动方式

双击仓库根目录的 `启动游戏.bat`，脚本会自动调用本机 Edge / Chrome 以桌面独立窗口模式（`--app`）加载 `index.html`。
