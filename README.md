# 众乐乐桌游 (PARTY TABLETOP • 多元桌游工坊)

面向 PC / Steam 平台规划的多人合集桌游客户端原型，采用零外部网络依赖的离线单页引擎与 Three.js WebGL 3D 桌面渲染。

## 已实现内容

- **大厅与开房系统**：暖阳黄白 / 夜间深空双主题、圆角 / 方正 UI 形态切换、画面亮度滑动条、主音量控制，以及单人人机 / 局域网 / 多人联机建房 3 步配置向导。
- **模式一：《日夜飞行棋》3D（实机可玩）**：
  - 4 套基于 3D 几何建模的手办级灵禽棋子（1P 蓝羽夜鸮、2P 晨曦灵雀、3P 冥夜紫鸦、4P 霞光粉鹦），实时离屏渲染 HUD 头像；
  - 17×17 经典对称十字飞行棋盘，底层搭载 **动态星空底板**（星云、闪烁星辰与流星）+ **星月湖畔实景舞台**；
  - 开局摇骰定先后顺序（点数越大越先、同点自动加赛、结果停留 8 秒）、完整飞行棋规则（自定义起飞点数、外圈同色 +4 顺风连跳、跨盘虚线快捷飞跃、踩子压扁+两波 3D 爆炸烟花返巢、6 步冲刺折返、投 6 连掷奖励、昼夜 8%/2% 奖惩机制）与启发式智能 AI；
  - **观众席、全员投票与 AI 接管底座**：首位胜者完赛触发 15 秒全员结束投票（满 3 票提前按进度结算），否则进入 `1x / 4x` 观众席继续观战直至 4 位全部完赛生成 1~4 名领奖台总榜，并内置 `seatControllers` 通用席位 AI 接管状态机。
- **模式二：《星轨五子棋》3D（实机可玩）**：
  - 宇宙行星星云全景舞台、`2048×2048` 深空占星盘、顺时针黄圈太阳与逆时针紫圈月亮双串环、180 颗浮动星尘，`虚空黑子` / `耀斑恒星` 3D 能量环棋子与 5 连星空烟花；
  - 支持 `星轨共鸣`（3+/4+ 连子点亮紫金连接光束）与经典双模式、左键旋转 / 正交俯视视角切换、开房自定义悔棋次数（关闭或 1~3 次）、落子 6 秒悔棋等待窗、人机 AI 回应与联机 10 秒对手同意弹窗底座、步数显示、`星象推演` 提示、换先及 3 档难度 AI（含 2-ply 前瞻）。
- **模式三：《机械大亨 (Gear Tycoon)》3D（实机可玩，完全对标蓝图大都会）**：
  - **图 2 蓝图三大架构**：
    - 48格【空中都市 · 天际走廊】（长条椭圆赛道，长宽比 2:1，双向直道与中央天际通讯塔）；
    - 64格【霓虹港湾 · 科技之都】（长宽比 1.3:1 港湾方台，中央全息发光能源球与自转能量环）；
    - 128格【超大都市 · 未来之城】（长宽比 1.3:1 宏伟外环大平台，中央超级帝国堡垒与主光柱）；
  - **中央赛博朋克夜景大都市**：中央彻底告别齿轮，构建高低错落的摩天大楼集群、程序化霓虹窗户夜景、楼顶航空警示脉冲呼吸灯，以及环城低空巡航赛博飞艇（自带喷气尾流）；
  - **超大加厚地格与超清 512×512 贴图（彻底解决文字看得清痛点）**：
    - 彻底移除所有挡视野的浮空全息广告牌；
    - 地格尺寸大幅做大至 `2.25 × 2.25`（厚度 `0.34`），采用 512×512 超清动态 Canvas 贴图（74px 超大图标、58px 超大粗体文字、44px 价格与标签），全景俯瞰一览无余；
  - **赛博专属 UI 与视听反馈**：
    - 顶栏搭载 **古铜色金属齿轮设置按钮**，360° 实时匀速自转；
    - 右下角搭载 **霓虹电子 LED 点阵屏幕骰子**，点击或空格掷骰触发高频数字抽选定格，驱动主角跳步前进；
    - 专属 **金色齿轮币（Golden Gear Coin）货币体系**，应用于现金、存款与交易流水；
    - 左侧 **蓝色霓虹玩家卡片**，展示机体状态（正常/住院关3天/囚禁等）、实际现金、银行存款、彩票号码、房产数、科技企业数 6 大关键指标；
  - **10 大特色地格全系实装**：
    - `GO 起点`（发薪 ⚙️2,000）；
    - `赛博重症医院`（住院隔离关玩家 3 天，预留属性升级工位）；
    - `机械囚笼`（智能锁死困人禁锢 1 回合无法掷骰）；
    - `电子笼网`（高压电击把玩家直接送进赛博医院关 3 天！）；
    - `中央银行`（分红/结算 ⚙️1,200）；
    - `量子折跃传送门`（空间奇点对角瞬移）；
    - `彩票店`（抽选乐透号码）；
    - `机械黑市道具店`（特种芯片与机件）；
    - `资源空投`（获得空投物资 ⚙️1,500）；
    - `系统过载`（排热罚金 ⚙️1,000）；
    - `芯片晶圆厂/高能光子矩阵等科技地产`（购置与过路租金收缴）；
  - **全景等轴测与多重视角**：默认采用图 2 同款大都会等轴测（Isometric）3D 俯瞰视角，同时支持【🎥 第三人称追焦】、【📐 自由轨道】与【🗺️ 正交俯视】一键切换。
- **规划模块（后续研发）**：赛博医院义体属性改造机制实装、专属个性化 3D 角色模型、局域网 / 多人联机同步通信。

## 本地启动方式

双击仓库根目录的 `启动游戏.bat`，脚本会自动调用本机 Edge / Chrome 以桌面独立窗口模式（`--app`）加载 `index.html`。
