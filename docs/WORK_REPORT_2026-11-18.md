### 阶段 A：地产产权并购、3 级 3D 实体建筑扩建与过路租金体系
1. **地块产权与租金核心闭环**：
   - 彻底实装地产产权持有机制（`tile.owner` 与 `tile.level`），区分街区工坊与战略科技企业；
   - 进驻敌方地产根据建筑等级（`1.0x / 2.2x / 4.0x`）精确计算并收取过路租金；若持有者已装备【量子算力核心】，名下战略科技企业租金额外获得 `+30%` 算力加成；
   - 租金支持现金直付与银行存款自动应急划扣。
2. **3 级 3D 实体建筑场景装配**：
   - 在 `markersGroup` 中为已购置产业实时构建对应阵营专属颜色发光的 3D 建筑：
     - **Level 1（微型机柜终端）**：深黑金属机柜 + 拥有者专属发光带 + 顶部自转悬浮能量环；
     - **Level 2（双塔数据中心）**：对称双塔阵列 + 霓虹横跨天桥连廊 + 建筑顶端双信标；
     - **Level 3（宏伟赛博摩天大厦）**：复合阶梯式摩天主塔 + 天台 Penthouse + **冲天垂直全息高能激光光柱（Vertical Light Beam）**；
3. **512×512 动态地格贴图自适应更新（`refreshTileTexture`）**：
   - 地块被购买或升级后，实时重新烘焙地格顶层贴图，醒目展现拥有者姓名（如 `[蓝调黑客] 拥有`）、建筑等级徽章（`Lv.1 ~ Lv.3`）以及最新过路租金，外立面与顶栏边框自适应切换为拥有者专属霓虹色彩。
4. **真人购置 / 扩建协商弹窗（`#modal-tycoon-property`）**：
   - 玩家停驻无主地块或自家产业时，弹出高科技赛博协商面板，直观展现地块图标、名称、类型、购置价格/扩建费用、预计租金收益及本人实时现金储备，支持 `[⚡ 立即投资]` 与 `[暂缓投资]`。

### 阶段 D：破产清算清退与大亨胜利统一结算
1. **破产清算机制（`handlePlayerBankruptcy`）**：
   - 当玩家资金链断裂（现金 + 银行存款不足以支付过路租金或惩罚罚款）时，宣告破产清算；
   - 播放专用破产沉降音效，棋子模型隐藏，名下资产按规则移交给债权人或释放归还市场，玩家卡片标记 `💀 破产清算`。
2. **唯一存活大亨胜出与统一弹窗（`triggerTycoonVictory`）**：
   - 当场上仅剩 1 位未破产玩家时，触发胜者加冕庆典，接入全局 `#modal-victory` 弹窗；
   - 详细展示冠军战报：净总资产估值、垄断产业处数、累计收缴过路租金总额；
   - 弹窗“再来一局”支持一键重新开局（`TycoonApp.restart`），“返回大厅”支持回到大厅向导。

### 阶段 E：4 类原生高保真 Web Audio 赛博音效
保持 0 外部音频文件依赖，通过 Web Audio API 振荡器与白噪声发生器合成了 4 类全新赛博音效：
- `cash`：3 声纯音快速上升清脆收银金币琶音（987Hz -> 1318Hz -> 1760Hz）；
- `upgrade`：高科技产业扩建与义体装配充能音（440Hz -> 659Hz -> 880Hz -> 1318Hz）；
- `shield`：脉冲防电磁护盾偏转吸收蜂鸣音（1400Hz -> 320Hz 锯齿波）；
- `bankrupt`：低沉下沉破产警示音（330Hz -> 247Hz -> 165Hz）。

## 三、下一步工作计划

基于目前三大游戏模式（《日夜飞行棋 3D》、《星轨五子棋 3D》、《机械大亨 3D》）均已实机可玩且具备完整单机 AI 与结算闭环的现状，下一步研发重点规划如下：

1. **《机械大亨》卡牌与突发事件系统（机械黑市 / 命运折跃卡）**：
   - 实装“机械黑市”抽卡机制（遥控骰子卡、强制征收令、资产置换协议、路障发生器），让走格子拥有更丰富的策略反制深度。
2. **专属 3D 角色模型与个性化义体外观**：
   - 为 6 位阵营主角（蓝调黑客、霓虹义警、智械先知、极客狂徒、矩阵财阀、暗影幽灵）制作更具职业辨识度的 3D 模型与专属特效。
3. **多人联机与局域网网络对战协议接入（WebSocket / WebRTC）**：
   - 目前三款棋类底层均已实现控制权与 AI 接管解耦，可正式将联机大厅 `#modal-online-lobby` 与局域网大厅 `#modal-lan-lobby` 接入轻量网络对战同步协议。
4. **游戏内背景音乐（BGM）与音效混音总线**：
   - 增加三种棋盘风格各异的轻量程序化背景音乐回路（国风星月湖畔、深空宇宙环境音、赛博朋克合成波 Synthwave），强化沉浸感。
