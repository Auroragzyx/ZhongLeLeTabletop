## 一、今日已完成研发内容

### 阶段：模式三《机械大亨 (Gear Tycoon)》3D 赛博朋克机械棋盘与大富翁地图系统（`window.TycoonApp`）

根据用户需求，在推进联机功能前，优先全力攻坚研发第三款核心游戏——大富翁玩法 3D 桌游《机械大亨 (Gear Tycoon)》，重点完成 3D 机械棋盘、真实咬合齿轮传动、高压蒸汽粒子爆发与 10 大特色地格机制。

#### 1. 赛博朋克 3D 机械棋盘与工业动力炉大都会
- **棋盘底盘与工业基座**：采用暗色碳素钢与钛金嵌边多边形底座（`deckGeo`），盘面环绕黄色高能警示光环与赛博全息地网（`#tycoon-grid-bg`），搭配深蓝/青/紫赛博霓虹多光源光影系统（`HemisphereLight` + `DirectionalLight` + `PointLight`）。
- **真实咬合齿轮传动组（Gear Train）**：
  - 研发实体凸齿机械齿轮生成器 `createGearMesh`，包含金属轮毂、辐射状渐开线凸齿、镂空辐条与轴心高亮盖帽；
  - 盘面中心布局 **4 组相切互咬齿轮**：
    - 中心主齿轮 $G_1$（鎏金黄铜，32 齿，基准转速 $\omega$）；
    - 右侧从动轮 $G_2$（赛博青钢，16 齿，齿比 $1:2$，角速度 $-2\omega$ 反向高速旋转）；
    - 左侧从动轮 $G_3$（深紫钛金，24 齿，齿比 $3:4$，角速度 $-\frac{4}{3}\omega$ 反向旋转）；
    - 上方从动轮 $G_4$（工业亮橙，20 齿，角速度 $-1.6\omega$ 反向旋转）；
  - 齿数与半径精确正比，角速度反向严格反比，实现机械结构在动力炉转速（120~180 RPM）下的精密真实咬合运转。
- **高压蒸汽喷气粒子系统（Steam Particle System）**：
  - 动力炉四周装配 4 组 45° 倾斜外翻的重型合金排气烟囱与泄压喷嘴；
  - 预构建 140 颗三维蒸汽粒子池（`SphereGeometry` + 半透明扩散材质），模拟初速喷射、热空气上升力、随机空气阻尼、膨胀扩散与透明度淡出；
  - **自动与手动泄压机制**：系统每隔约 3.6 秒自动触发一次高压蒸汽脉冲（动力炉提速至 180 RPM，核心高亮过载闪烁）；顶栏提供【💨 手动泄压喷气】按钮，点击即刻咆哮泄压并触发 Web Audio 白噪声带通滤波模拟的真实高压气动嘶鸣音效（`playSound('steam')`）。

#### 2. 大中小三档地图规模与 2~6 人席位自定义配置
- **三档地图环路（48格 / 64格 / 128格）**：
  - **小地图（48格）**：边长格数 $S=12$，半宽 $W=11.5$，极速遭遇，高密度触发特殊事件；
  - **中地图（64格，标准推荐）**：边长格数 $S=16$，半宽 $W=14.4$，经典大富翁环路节奏；
  - **大地图（128格）**：边长格数 $S=32$，半宽 $W=24.0$，宏伟回廊，深厚资金规划与多工坊街区；
  - 在建房向导第 3 步《配置玩家自定义专属规则》中采用大中小单选卡片直观选择；棋盘网格尺寸、摄像机距离与核心动力炉规模随地图档位自动平滑自适应。
- **2~6 人多玩家阵营席位**：
  - 登场角色阵容：`1P 蓝调黑客 (你)`、`2P 霓虹义警 (AI)`、`3P 智械先知 (AI)`、`4P 极客狂徒 (AI)`、`5P 矩阵财阀 (AI)`、`6P 暗影幽灵 (AI)`；
  - 初始启动资金可自由配置：₡10,000 / ₡15,000 (推荐) / ₡25,000 / ₡50,000；
  - 双列悬浮 HUD 玻璃卡片：左侧容纳 1P~3P，右侧容纳 4P~6P，实时展示资金、当前所在格编号与地名、行动中徽章及机体运行状态。

#### 3. 用户指定的 10 大特色地格与 3D 全息悬浮标记
在所有地图规模中，四大核心地标固定于四角，其余边长对称散布各类特色功能格，每格均搭载动态 Canvas 贴图（标明编号、图标、名称与租售价）以及专属 3D 悬浮全息标记：
1. **赛博起点（`start`，角 0）**：3D 赛博门楼，经过或停驻可领取 ₡2,000 齿轮津贴，机能充能；
2. **赛博朋克重症医院（`hospital`，角 1）**：
   - 3D 悬浮自旋发光绿十字；
   - **住院隔离关玩家 3 天机制**：被收治或因事故入院时，强制住院隔离 3 天（3 回合无法行动）；
   - **义体属性升级工位**：预留机体动力与算力属性改造扩展接口；
3. **义体中央银行（`bank`，角 2）**：3D 悬浮自旋黄金金币模型，停驻结算能源利息分红 +₡1,200；
4. **机械囚笼（`cage`，角 3）**：4 根激光立柱与防护顶盖，停驻触发智能锁死，禁锢暂停行动 1 回合；
5. **电子笼网（`emp_grid`）**：
   - 3D 双重旋转高压电弧环；
   - **高压电击送医机制**：玩家踩中立刻遭遇高压脉冲强力电击，机体电路严重烧毁，**强制直接移送进【赛博医院】隔离住院 3 天**！
6. **量子折跃传送门（`portal`）**：3D 紫色折跃虫洞光环，踩中触发超空间微型虫洞，瞬间折跃瞬移至对角传送门；
7. **霓虹博彩彩票店（`lottery`）**：3D 悬浮粉红八面彩晶，停驻免费抽奖赢取 ₡800 暴击奖金；
8. **机械黑市道具店（`item`）**：3D 悬浮金黄机件工具环，获取战术过载芯片提升机能；
9. **天基赛博空投（`reward`）**：3D 悬浮空投物资箱，获得补给金 +₡1,500；
10. **反应堆过载惩罚（`penalty`）**：3D 悬浮红色警示锥，过热反冲支付应急排热处理费 -₡1,000；
11. **赛博工坊/街区（`property`）**：钛金工坊、芯片工厂、光子矩阵等地产地格，支持购置与支付过路租金。

#### 4. 全息地格终端（Tile Inspector）与交互控制
- **Raycaster 3D 拾取与悬停反馈**：鼠标掠过地格自动出现黄色线框高亮并变为手型指针；点击任意地格即锁定青色全息选框，右下角【赛博地格全息终端】毫秒级刷新对应地格的编号、名称、地标分类、机制详述与租售价格；
- **镜头对焦（`focusSelectedTile`）**：点击全息终端的【🔍 对焦】按钮，摄像机平滑滑行聚焦至当前选中地格；
- **行棋推演（`testRollAndMove`）**：支持点击按钮或按 `Space` 空格键投掷 1~6 点骰子，机能棋子沿环路平滑跳步前进，触发起点加薪、特色地格机制与玩家卡片更新，并自动交替玩家回合。
