### 阶段 D：中央摩天大楼赛博窗户夜景贴图自发光化与地表科技回路重塑（重点解决“大楼黑漆漆、地面纯青板”痛点）

根据用户最新测试反馈，针对“大楼城市无贴图、黑漆漆、中间地面纯青色实心板”的问题进行了彻底根除与材质重塑：

1. **摩天大楼全面实装 512×512 璀璨赛博夜景窗户贴图（告别黑漆漆）**：
   - **痛点根因**：原材质漫反射底色过暗（`0x0B1220`）且未开启自发光贴图（`emissiveMap`），导致在夜景阴影下所有贴图颜色被乘法压成死黑。
   - **重构方案**：
     - 采用 **512×512 高清 Canvas 动态烘焙窗户贴图**：横向设有楼层工字钢分割梁（`#1E293B`），纵向设有深色百叶窗立柱，内嵌密集的成排成列高密度窗户发光矩阵；
     - 窗户多态发光：青蓝（`#00E5FF`）、天蓝（`#38BDF8`）、霓虹紫粉（`#EC4899`）、科技明黄（`#FDE047`）、亮白照明（`#FFFFFF`）与暗窗混合；
     - **材质全面升级为双通道高强度自发光**：`color: 0xFFFFFF`（白色漫反射，不削弱贴图本身），`emissive: 0xCCDDF4`，配合 `emissiveMap: winTex` 与 `emissiveIntensity: 0.95`！使每一幢大楼在夜幕下均呈现出流光溢彩的自发光效果，彻底告别暗黑方块。

2. **建筑边缘赛博霓虹发光轮廓线（EdgesGeometry 线框微光）**：
   - 为每幢摩天大楼自动生成几何边缘轮廓发光线（`LineSegments`），采用青蓝（`0x00E5FF`）、霓虹粉（`0xEC4899`）与冰蓝高亮色彩；
   - 让大楼在三维空间中轮廓锐利分明，充满图 2 蓝图同款的未来科幻线框感。

3. **大楼阶梯式造型与外立面全息广告巨幕**：
   - 高楼均搭载顶层缩进式阶梯建筑造型（Penthouse / 天台机房 / 停机坪），顶端配有金属天线塔与正弦波呼吸闪烁的红色/青色航空警示信标；
   - 大楼立面外侧挂载巨型半透明发光霓虹广告牌（印有 `CYBER CORP`、`NEON CITY`、`AI MATRIX`、`G-TYCOON` 等字样），大幅增强商业繁华感。

4. **彻底移除纯青色实心板，重构深空高科技电路地表与精致边缘导轨**：
   - **痛点根因**：原基座外导轨使用了实心 `BoxGeometry`，错误地将内部整个地盘完全铺满，呈现一大块刺眼的纯青色。
   - **重构方案**：
     - 彻底删除实心大板，中央基座铺设 **512×512 科技电路网格地表贴图**（深墨蓝地底、细微科技网格、青蓝电路走线与发光节点），具备极佳的金属度与反光质感；
     - 四周导轨改用 **真正贴合在边缘四周的 4 条超细微发光边框**（宽度仅 `0.18`），绝不遮挡内部地表。

5. **中心地标与飞艇巡航持续协同**：
   - 64格中央全息能量球（内核线框脉冲球 + 45° 倾斜能量光环 + 4 组垂直发光柱）；
   - 48格中央天际通讯高塔（多节塔身 + 环形观景台 + 冲天垂直全息激光束）；
   - 128格中央帝国超级主堡垒（金字塔复合基座 + 高耸主塔 + 冲天紫金主光柱）；
   - 空中巡航飞艇带发光尾翼与双喷气尾流平稳环城飞行。
