### 阶段 B：赛博独立 UI 全面重构、第三人称追焦与大富翁10圆角大道（今日重点升级）

根据用户提供的高清赛博大富翁素材与专属 UI 指令，对《机械大亨》进行深度重塑：

1. **导入赛博朋克霓虹全景背景（`assets/bg_tycoon_cyber.jpg`）**：
   - 提取素材中的霓虹摩天楼、MONOPOLY 全息屏、飞天跑车、摩天轮与地面水洼倒影，深度融入 `#tycoon-scenic-bg.cyber-atmosphere`，渲染通透的赛博朋克大都会氛围。
2. **实时转动古铜色金属齿轮设置按钮（`#btn-tycoon-settings`）**：
   - 将原普通文字按钮重构为高精度**古铜色多齿金属齿轮**（包含渐变轮毂、8 组辐射齿与金属轴心），搭载 `@keyframes spinBronzeGear` **实时 360° 无缝匀速自转**，悬停散发琥珀色霓虹微光。
3. **霓虹电子 LED 点阵屏幕骰子系统（`#cyber-dice-neon-box`）**：
   - 参照素材右下角霓虹发光骰子，设计暗晶半透立方外框与蓝紫霓虹倒角光边；
   - 告别传统手绘点数，配备 **高科技电子 LED 点阵屏幕**（`#cyber-dice-led-screen`），内置扫描线网格与大字点阵数字（`#cyber-dice-val`）及 6 颗动态点阵 LED 灯；
   - 点击或按 `Space` 掷骰时，触发高频数字交错随机抽选与电子蜂鸣脉冲动画，定格后爆发高亮青蓝辉光。
4. **金色齿轮币（Golden Gear Coin）货币体系**：
   - 将通用的 `₡` 货币符号全量替换为专属 **金色齿轮币图标**（`getGoldenGearSvg()`），贯穿实际现金、银行存款、地产买卖与战报播报，强化机械大亨核心工业元素。
5. **左侧蓝色霓虹玩家信息版（严格实装用户要求的 6 大关键数据）**：
   - 采用赛博青蓝高透毛玻璃与电弧霓虹框线（`.blue-neon-player-card`，当前行动角色具备呼吸光晕）；
   - 结构清晰列出 6 项专属参数：
     1. **机体状态**：`🟢 运转正常` / `🏥 住院隔离中(关3天，剩X天)` / `🔒 机械囚笼禁锢(剩X回合)` / `⚡ 触电急救中`；
     2. **实际现金**：金色齿轮币图标 + 动态金额大字；
     3. **银行存款**：`🏦 银行存款: X 齿轮币`（随中央银行分红及存款动态结算）；
     4. **已购买彩票号码**：`🎰 彩票号码: #88 (已投注)` / `暂未购买`（彩票店抽得）；
     5. **拥有房产数量**：`🏙️ 拥有房产: X 处`；
     6. **拥有科技企业数量**：`🏢 科技企业: X 家`（全资控股芯片晶圆厂、高能光子矩阵等战略科技资产）。
6. **大富翁 10 风格圆角大道地图架构（告别方方正正）**：
   - 参考《大富翁10》赛道曲线设计，算法引入圆角弧度 $R_c$（3.6 ~ 6.0 单位），将 4 条笔直干道与 4 处转角通过 90° 平滑圆弧无缝连接；
   - 每枚地格均沿大道行进切线角度旋转（`rotation.y = yaw`），告别生硬直角；
   - 铺设深色高反光柏油路基，沿整条大道外沿加装 **粉红霓虹外导轨**，内沿加装 **青光赛博内导轨**，极具未来赛车与大富翁赛道质感。
7. **第三人称主角追焦视角（彻底解决文字看不清痛点）**：
   - **默认采用第三人称跟随视角（`cameraMode = 'follow'`）**：摄像机低空平滑悬浮于当前行动主角后上方（距离 6.6、高度 3.4），向前俯瞰整条赛道；
   - 玩家视野正前方的大道地格以近景大特写呈现，地格升级为 **256×256 高清 Canvas 贴图**，大字极其锐利醒目；
   - 在特色地格正上方追加 **3D 浮空全息广告牌（Floating Billboard Sprites）**（如 `🏥 赛博医院 • 关3天`、`⚡ 电子笼网 • 电击进院`），无论视角如何转动始终面向镜头，清晰直观；
   - 行棋跳步时摄像机宛如极品飞车般顺滑平移跟拍，转角自动圆滑掠过；点击视角按钮亦可随时切回【📐 3D自由轨道】或【🗺️ 正交俯视】。
